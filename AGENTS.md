# AGENTS.md

Agent behavior guidelines generated by RepoRank.

## Security

- **🔴 No eval() in production code** — eval() allows arbitrary code execution and must never appear in production code.

## Code Quality

- **🟡 Extract URLs and configuration to env vars** — Hardcoded URLs and configuration values prevent environment-specific deployments.
- **🔴 Handle async errors properly** — Every async function must have try/catch or .catch() handler. Unhandled rejections crash the process.
- **🟡 Remove debug code before committing** — console.log, debugger statements, and TODO/FIXME comments should be removed or tracked in issues.
- **🟡 Keep files under 300 lines** — Small files are easier for both humans and AI to reason about. Files over 300 lines should be split.
- **🟡 Write tests for core functionality** — Core business logic should have tests. CI should run tests on every PR.
